Temporal Entanglements, an interactive map of St. Louis cultural events

Temporal Entanglements is an interactive map of St Louis that shows the cultural events of the upcoming month. I created it for personal use to keep myself informed about the city’s happenings. It is not a comprehensive map; I picked the venues based on my own interests and places that I often tend to go to. The code is written using Claude Code and it is available on my GitHub. Separable or inseparable, correlated or uncorrelated, entangled or unentangled points appear and disappear in the city’s landscape, forming our experiences, life, and memory of past time.
